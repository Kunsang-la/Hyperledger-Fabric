# Distributed Multi-Node Hyperledger Fabric Deployment

## Objective

Production-style Hyperledger Fabric deployment consisting of:

- 3 Organizations
- 6 Peer Nodes
- 1 Raft Orderer
- Fabric CA
- Asset Transfer Smart Contract
- Multi-Organization Transactions

## Technologies

- Ubuntu Server 22.04
- Docker
- Docker Compose
- Hyperledger Fabric 2.5
- Fabric CA
- Go
